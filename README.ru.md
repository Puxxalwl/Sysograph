# Sysograph

**Свободный и полностью оригинальный диспетчер задач для Linux.**

[English version](README.md)

![Скриншот](docs/screenshot-processes.png)

Sysograph — нативное Linux-приложение, написанное с нуля на современном C++
с GTK 4, которое показывает полную картину работы системы: процессы,
производительность, пользователей, службы и автозапуск.

* **100 % свободное ПО.** Весь проект распространяется по GPL-3.0-or-later
  и связывается только со свободными библиотеками (GTK 4 / GLib,
  LGPL-2.1+). См. [NOTICE](NOTICE) и
  [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
* **Оригинальная разработка.** Ни код, ни графика, ни иконки, ни тексты
  проприетарных вендоров (включая Microsoft) не копировались и не
  заимствовались. Название, логотип и интерфейс — собственная разработка
  проекта. Приложение не аффилировано ни с одной компанией или продуктом.
* **Без root, без сети, без сбора данных.** Программа читает только
  стандартные, публично документированные интерфейсы `/proc`, `/sys` и
  общепринятые соглашения автозапуска XDG.

## Возможности

| Вкладка | Что даёт |
|---------|----------|
| **Процессы** | Живая таблица всех процессов: имя, PID, пользователь, ЦП %, память, состояние, потоки, приоритет, командная строка. Поиск по мере ввода, сортировка кликом по заголовку, панель подробностей (путь к исполняемому файлу, рабочий каталог, число открытых файлов, время запуска, время ЦП) и аккуратное завершение процессов (SIGTERM) с опцией принудительного завершения (SIGKILL). |
| **Дерево процессов** | Те же данные в виде иерархии «кто кого породил» с раскрывающимися узлами, состояние которых сохраняется при обновлении. |
| **Производительность** | Графики в реальном времени: суммарная и поядерная загрузка ЦП, память и swap, дисковый и сетевой трафик, а также аптайм, число активных/заблокированных процессов и заполненность корневой ФС. |
| **Пользователи** | Агрегация по учётным записям: число процессов, ЦП %, память, потоки. |
| **Автозапуск** | Элементы автозапуска XDG с источником (пользовательский/системный) и статусом, включение/отключение одним кликом через стандартные пользовательские `.desktop`-переопределения — без root. |
| **Службы** | Список юнитов systemd (состояние, под-состояние, описание) только для чтения; обновляется прямым вызовом `systemctl`, без shell. |

Детали качества, которые важны:

* Все парсеры `/proc` устойчивы к битым, обрезанным или исчезнувшим
  записям — завершение процесса посреди чтения не может уронить
  приложение.
* ЦП % процесса корректно нормируется на полную мощность машины (все
  ядра) — так, как этого ожидают пользователи.
* История для графиков хранится в кольцевых буферах фиксированного
  размера: потребление памяти не растёт за сутки работы.
* Гонки повторного использования PID учтены: диалог завершения всегда
  показывает имя процесса, зафиксированное в момент запроса.
* Интервал обновления (1/2/5 с) выбирается в меню заголовка.
* Интерфейс на английском и русском языках; язык определяется локалью
  (`SYSSOGRAPH_LANG=en|ru` для принудительного выбора).

## Сборка из исходников

Понадобятся компилятор C++20, CMake ≥ 3.16, pkg-config и dev-пакеты GTK 4.

```sh
# Debian / Ubuntu
sudo apt install build-essential cmake pkg-config libgtk-4-dev

# Fedora / RHEL
sudo dnf install gcc-c++ cmake pkgconf-pkg-config gtk4-devel

git clone <адрес-репозитория> sysograph && cd sysograph
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/sysograph
```

Подробнее (отладочная сборка, тесты) — в [BUILDING.md](BUILDING.md).

## Установка

```sh
cmake --install build            # классическая установка
```

или установите пакеты, собранные CPack:

```sh
cd build && cpack
# -> sysograph-0.1.0-Linux.deb   (Debian, Ubuntu и производные)
# -> sysograph-0.1.0-Linux.rpm   (Fedora, RHEL и производные)
```

Инструкция по AppImage — [packaging/appimage/README.md](packaging/appimage/README.md).
